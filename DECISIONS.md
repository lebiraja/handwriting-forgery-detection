- Novelty check (web search, 2026-11-05): teacher-student distillation already exists in writer verification (Priya et al. 2025, GCN) and signature verification (arXiv 2308.01136), so distillation is described as an adopted technique, not a contribution. Calibrated LR with an inconclusive outcome has forensic precedent (CEDAR-FOX, Chu NIJ); score-level fusion has older precedent. The claimed contribution is the combination (page-level, deep, multi-reference, content-matched negatives, cross-dataset and AI-forgery evaluation); no writer-ID work with content-matched negatives was found. Wording stays "to our knowledge".

Skipped. No AI imitation of specific writers is evaluated; the paper says so. Fallback: the Kaggle real-vs-generated set, whose "generated" pages are font-rendered text (folder names such as ccursive, schoolbell2, better grade), used only to measure how often synthetic pages are accepted against real references (a synthetic-impostor false-accept rate). It must not be described as AI-forgery detection.

## 2026-11-06 (final evaluation)
- Final evaluation was run once per seed (`train/final_eval.sh`): test + Firemaker + synthetic pages, test baselines, attention/deletion test. Synthetic-page false-accept code was added to `eval.py` BEFORE the run (after checking the Kaggle pages embed on validation-free data).
- CORRECTION 1 (found after seeing test output, mistake in my code, not a tuning choice): `eval.three_way` produced tau_high < tau_low on IAM (accept at >=0.85, reject at <=0.92) because IAM is separable on validation, so one score could be both accepted and rejected (accepted + rejected > 100%). The rule is now: if the two thresholds would overlap, use one midpoint threshold and no inconclusive band. Fixed in `eval.py` and applied to the saved test scores by `train/src/verdict.py` (no model re-run, thresholds from validation only). The uncorrected numbers in `eval_test.json["three_way"]` are not used in the paper.
- CORRECTION 2 (analysis design flaw, found after seeing test output): in `eval.py` multi-reference trials draw genuine queries only from writers with >= N+1 pages, so the writer set shrinks as N grows (IAM test: 99, 56, 45, 17 writers for N = 1, 2, 3, 5) and N is confounded with writer difficulty. Added `train/src/multiref.py`: one extra embedding pass on the test pages with the same model and no tuning, evaluating every N on ONE fixed writer set (nested references, same impostor queries). The paper reports this version; the confounded curve is not used.
- Ablation outcome (validation, 1 seed, 40 epochs): the full model (mean EER 5.35%) is worse than no-distillation (4.38), no content-matching (4.57) and no augmentation (4.88). With one seed and seed spread of about 0.4 (main runs, 120 epochs) these differences are not evidence that an ingredient hurts, and none of the ablations shows a clear benefit. The paper says so and does not claim ingredient-level wins.
- Attention deletion test: dropping the 25% most attended patches lowers the same-writer score by 0.0043 against 0.0022 for random patches (60 pairs, sd 0.04), so attention is only weakly faithful. The paper presents heatmaps as visualisation, not explanation.
